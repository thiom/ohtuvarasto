## Web-käyttöliittymä

Käynnistä sovellus komennolla

```
uv run flask --app src/app run
```

ja avaa selaimessa http://127.0.0.1:5000. Varastot säilytetään muistissa, joten ne katoavat, kun palvelin käynnistetään uudelleen.
